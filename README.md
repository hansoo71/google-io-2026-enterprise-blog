# Google I/O 2026 Enterprise AI Blog

Korean expert editorial HTML report comparing Google I/O 2026 enterprise AI announcements with AWS Bedrock AgentCore and Microsoft Azure Foundry / AI Gateway.

## Output
- Source: `src/index.html`, `src/styles.css`, `src/app.js`
- GitHub Pages build: `docs/index.html`
- Images: `assets/images/`, copied into `src/assets/images/` and `docs/assets/images/`
- Evidence: `docs/source/source-notes.md`
- Design reference: `docs/source/wired-DESIGN.md`

## Design
Selected getdesign.md style slug: `wired`.
The page uses the editorial rhythm, stark black/white canvas, serif headline density, hairline grids, and magazine-like data-story layout from the fetched DESIGN.md. It does **not** include any WIRED logo, wordmark, masthead image, or external logo asset.
